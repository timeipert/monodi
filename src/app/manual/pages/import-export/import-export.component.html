Import / Export

The Import / Export page (in the top navigation bar) gathers every way of moving chant data in and out of your workspace. This page explains each format and the two chant-specific tools added for interoperability with the CANTUS ecosystem: Volpiano and the Cantus Index import.

Where the actions live

  • Import / Export page (nav bar) — the hub: workspace backups, ZIP, HTML edition, CSV, and Cantus import.
  • Document toolbar — per-document exports: JSON, PDF, MEI and Volpiano.
  • Source page — New Document, Import Volpiano; the document page also has Import Text.

Workspace formats

  • Workspace JSON (.monodijson) — the recommended lossless full backup: every source, document, transcription and your settings in one file.
  • ZIP — a monodi-/OMMR4all-compatible corpus archive; import auto-detects either layout.
  • HTML edition — a self-contained static site of your corpus (rendered notation, browsable metadata, built-in search) for publishing or sharing read-only.

CSV (metadata + melody + text)

CSV is a spreadsheet-friendly exchange format, not a full backup. On Export CSV a dialog lets you choose what to include — source metadata, document metadata, and content — and only columns that actually contain data are written (one row per document).

  • Metadata columns are prefixed source_ and document_; custom fields appear as source_custom_<key> / document_custom_<key>.
  • A melody column holds the chant in Volpiano, and a text column holds the sung text as space-separated syllables (Quo ni am de us), aligned one-to-one with the melody.
  • Import CSV creates new sources/documents and updates existing ones (matched by id); it never overwrites the richer notation of a document that already exists — only metadata is updated.

Sections and the critical apparatus are intentionally out of scope for CSV; use JSON/ZIP to preserve them.

Volpiano

Volpiano is the plain-text chant encoding used by the CANTUS Database. Monodi-Zero reads and writes it following the CANTUS Volpiano Protocols.

  • Export Volpiano (document toolbar) — copies the current chant's Volpiano to the clipboard and downloads a .txt.
  • Import Volpiano (source page) — paste a Volpiano string to create a new document under that source. An optional aligned-text field (Quo-ni-am de-us) places the sung text under the notes.

Pitches follow the standard non-transposing treble mapping (b = middle C). Adjacent letters are a ligature; - separates neumes, -- syllables, --- words. Uppercase letters are liquescents. Anything the parser doesn't recognise is skipped and reported as a warning rather than failing the import.

Import chant by Cantus ID

On the Import / Export page, Import chant by Cantus ID fetches melodies live from cantusindex.org. Enter a Cantus ID (e.g. 501001) or paste a cantusindex.org/id/… link and click Fetch.

  • Each manuscript witness of that chant is listed with its siglum, folio, mode and a melody preview. Tick the ones you want and click Import.
  • Each becomes a new document; a matching source is created (or reused) from the manuscript siglum. Genre, feast, incipit and the full text are stored as metadata.
  • By default only the melody and metadata are imported (syllable text left blank).

Experimental: split text into syllables

The tick-box Split text into syllables (experimental) additionally places the Latin text under the notes. The databases do not serve a pre-split text — and cantusdatabase.org cannot be read directly from the browser — so Monodi-Zero uses the melody's own syllable structure (the --/--- boundaries) to split the text locally with a Latin heuristic. It is best-effort: where the text and melody don't line up exactly, the chant is imported anyway and a notice tells you to check the text. Always proofread the result.
